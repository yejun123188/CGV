# 🎬 멀티플렉스 영화 예매 웹 서비스 프로젝트

## 📌 프로젝트 소개
대형 멀티플렉스 영화 예매 사이트를 벤치마킹하여, 웹 표준을 준수하고 사용자의 동선을 고려한 인터랙티브 예매 웹사이트를 구축한 팀 프로젝트입니다. 기술적 한계를 뛰어넘어 사용자 중심의 직관적인 예매 인터페이스를 구현하는 데 집중했습니다.

## 🛠 사용 기술 스택
- **Frontend:** HTML5, CSS3, JavaScript
- **Key Concepts:** 웹 표준(Semantic Markup), 반응형 웹, UI/UX 설계, 인터랙티브 팝업 플로우

## 🙋‍♀️ 나의 주요 역할 및 기여
- **서비스 기획 및 UI/UX 설계:** 사용자 여정(User Journey)을 분석하여 예매 프로세스를 최적화하고, 시각적 위계(Hierarchy)를 고려한 인터페이스 구조를 설계했습니다.
- **메인 페이지 퍼블리싱:** 그리드 레이아웃을 도입하여 방대한 프로모션 콘텐츠를 시각적으로 명확하게 구조화했습니다.
- **핵심 예매 로직 구현:** '날짜/시간/좌석 선택' 팝업 플로우를 논리적으로 구성하고, AI 협업을 통해 동적 인터랙티브 기능을 완성했습니다.
- **문제 해결:** JavaScript 학습 초기라는 기술적 한계를 기획적 사고와 AI 협업 능력으로 극복하여, 교육 과정 중 수준 높은 예매 시스템을 구현했습니다.
